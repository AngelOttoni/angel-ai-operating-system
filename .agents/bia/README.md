# Bia operational workspace

This workspace supports Bia's work as Documentation Engineer under the repository's `AGENTS.md`.

- `context/`: dated handoffs and evidence-based project state.
- `instructions/`: detailed operational policies subordinate to repository instructions.
- `reports/`: reviews, findings, and delivery reports.
- `work/`: temporary drafts and intermediate material.

These materials support execution and continuity. They have no normative authority and do not override `AGENTS.md`, the Project Charter, architecture documents, ADRs, ABRS, or AOS. A workspace draft or report is not an approved specification.

Canonical engineering artifacts must remain in the official repository documentation structure, organized by architectural responsibility. Reference those sources rather than maintaining competing copies here.

Do not record credentials, tokens, secrets, authentication material, absolute machine paths, hostnames, or other machine-specific facts or configuration.
